# 🚀 Lista de Tarefas 

> Meu primeiro projeto prático desenvolvido em **Ciência da Computação** para aprender os fundamentos do desenvolvimento Front-End!

## 💻 Sobre o Projeto
Uma aplicação web simples e interativa de lista de tarefas que permite adicionar novos itens, marcar tarefas como concluídas (com efeito de risco) e removê-las da lista.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação da página.
* **CSS3:** Estilização, design moderno com tema escuro e responsividade.
* **JavaScript (Vanilla):** Manipulação do DOM, eventos de clique e lógica de interação.

## ⚙️ Como Executar o Projeto
1. Clone este repositório ou faça o download dos arquivos (`index.html`, `style.css`, `script.js`).
2. Abra o arquivo **`index.html`** em qualquer navegador de internet (Chrome, Edge, Firefox, etc.).
3. Divirta-se adicionando suas tarefas!
